# UI guidance

Apply this guidance to any user interface, including web, native, mobile, desktop, and terminal UIs. Respect the project's existing conventions and dependencies. Prefer the target platform's standards and native primitives.

For web UIs, prefer web standards, modern CSS, and contemporary native browser primitives.

Never narrate UI to the user by including explanatory text around the UI elements.  Never over-document or leak our conversation into UI presentation.
